How this works

The wave calculation

There is no wave buoy anywhere in these waters, so wave height is calculated from forecast wind and each leg's fetch using JONSWAP fetch-limited growth:

g·Hs/U² = 0.0016·√(g·F/U²)      g·Tp/U = 0.286·(g·F/U²)^⅓

Valid here because no ocean swell reaches inside Haro Strait — everything you meet is locally generated wind sea, which is exactly what this law describes.

By hand: Hs ≈ wind(kn) × √fetch(km) / 120. Since fetch is fixed per leg, that's one divisor each — Sidney Channel in a southeasterly is wind ÷ 20, Swanson ÷ 24, Ganges approach ÷ 28, Satellite ÷ 31, Colburne ÷ 38, Sidney Channel in a northwesterly ÷ 49.

Seas need time to build. The formula gives the fully developed sea; reaching it takes 4–6 hours over Haro Strait fetch, about 2 in the sheltered passages. A southeasterly that came up an hour ago has made roughly a third of the table value.

Wind against current, and why rips form

On an opposing current a wave shortens and steepens:

c/c0 = ½(1 + √(1 + 4U/c0))
H/H0 = 2 / [(1 + √(1+4U/c0))·(1+4U/c0)^¼]      c0 = 1.56·T

That height ratio diverges at U = −c0/4 — the blocking limit, where the wave cannot propagate and breaks. That is what a tide rip is.

Same wind, same water, 77% more wave height depending only on tidal phase. In the last row the height falls because the sea has broken down into short steep chop. That is worse, not better, and the page says so rather than letting a smaller number read as improvement.

Tuning it to your boat

Everything lives in the <script> block at the top of this file. No build step, no dependencies — edit and commit.

  • fetch (inside each leg) — the biggest lever. Open-water km to the nearest upwind land, per sector, for the direction wind blows from. These are chart estimates; if a leg reads wrong, fix these first.
  • LIMITS — the green/yellow/red bands. Start conservative, loosen slowly.
  • BOAT.cruiseChop — used for transit and fuel once Hs exceeds chopThreshold. Budgeting the slow number stops you pushing a marginal call because you're running late.
  • floodSet — true bearing the flood sets on that leg; drives the wind-against-current test.
  • peakKn — scales the derived current.

Keep a log. After each trip note what the page said and how the boat felt. A season of that beats any default here.

If tides won't load

The page asks the Canadian Hydrographic Service for tides directly. Some browsers block that (CHS doesn't send the header that permits it). If you see the "tides unavailable" warning every time, add two files to this repo and GitHub will fetch the data for you nightly.

1. scripts/fetch_tides.py — a short script that pulls 8 days of predictions for Sidney and Active Pass and writes data/tides.json. The page picks that file up automatically.

2. .github/workflows/update.yml:

name: Refresh tides
on:
  schedule: [{ cron: "20 11 * * *" }]
  workflow_dispatch:
permissions: { contents: write }
jobs:
  refresh:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "3.12" }
      - run: python scripts/fetch_tides.py
      - run: |
          git config user.name github-actions
          git config user.email actions@github.com
          git add data/tides.json
          git diff --staged --quiet || (git commit -m "tides" && git push)

Then set Settings → Actions → General → Workflow permissions to Read and write. Until you do, wind and waves still work — you just lose currents and slack.

Limits worth knowing
  • Currents are derived from the rate of change of the tide curve, not published current tables. Slack timing is about right; the rate is indicative. For a narrow pass — Active Pass, Porlier, Pender Canal — use the official tables.
  • Beyond about 48 hours the wind model falls back from HRDPS to a coarser global one that doesn't resolve funnelling between the islands. The page tells you which it used.
  • Wave heights are calculated, not measured. A model of a model.
  • Nothing here knows about fog, and fog is what most often catches an open boat with no radar on an August morning. Read the visibility line in the official forecast.
Wave heights are calculated from forecast wind and per-leg fetch — there is no wave buoy in these waters. Wind comes from Open-Meteo, pinned to Environment Canada's HRDPS model where it reaches. Tides come from the Canadian Hydrographic Service.

This does not replace the official forecast. Read the Haro Strait marine forecast and check the live station observations every time. File a float plan. Monitor VHF 16.
